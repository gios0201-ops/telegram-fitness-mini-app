# Мобильный интерфейс и полный PPL

## Почему видны три упражнения

При чтении `fit_v1_plan` и сохранённых дней `fit_v2_plan_*` используется пользовательская программа. Новый шаблон из 23 упражнений не заменяет её автоматически. Старый стартовый план содержит по три упражнения в каждом дне — это воспроизведено тестом. Данные конкретного Telegram-аккаунта удалённо не читались; содержимое его CloudStorage нельзя подтвердить по локальному репозиторию.

## Установка полной программы

В «Тренировки» нажмите «Установить полный PPL-план», проверьте предварительный просмотр и нажмите «Подтвердить установку полного плана». Отмена и первое чтение ничего не записывают.

Программа группируется так: PUSH — грудь / передняя и средняя дельта / трицепс (4/2/2); PULL — спина / бицепс / задняя дельта (5/2/1); LEGS — квадрицепсы / задняя поверхность бедра и ягодицы / икры (3/3/1). Всего 23 упражнения. Пользовательские упражнения с неизвестным ID получают общую группу по указанной мышце.

Установка создаёт девять страниц `fit_v3_plan_<UUID>_*`: три новых дня, три копии текущей программы и три копии программы для привязки старой истории. После подтверждения чтением всех страниц записывается указатель `fit_v3_active_plan`. При ошибке до записи указателя остаётся прежняя активная программа; частичные копии не удаляются автоматически. Исходные v1/v2 ключи сохраняются. Повторная установка также сохраняет текущую редакцию программы.

Старая программа доступна в полном JSON-экспорте («Профиль → Экспорт JSON»), в страницах `before_*`. Программа для привязки исходных v1-подходов заморожена отдельно: переименование новой программы и установка шаблона не меняют ID старой истории. Тренировки, питание, профиль и замеры не перезаписываются при установке. Упражнения, отсутствующие в активной программе, остаются доступны через архив истории. Автоматического восстановления резервной программы интерфейс пока не предлагает.

CloudStorage не предоставляет транзакций/CAS. Перед активацией проверяются известные исходные страницы; между проверкой и записью остаётся окно гонки. Избегайте одновременной установки программы с двух устройств. Размер каждой страницы ограничен 4096 символами; резервный лимит — 900 ключей с учётом сторонних данных.

## Интерфейс

Общий компактный header, единая типографика, тёмная тема с синим акцентом, SVG-иконки навигации. Карточки упражнений содержат схему мышц, точную группу, диапазон и число сегодняшних подходов; техника скрыта в раскрывающейся секции. Каталог поддерживает поиск и остаётся вспомогательным.

Питание показывает четыре полосы прогресса, съеденное / цель и остаток. Добавление и редактирование открывают отдельную форму. Цель калорийности остаётся ориентировочной; количество приёмов пищи не задаётся.

Прогресс показывает последнюю измеренную массу, изменение между доступными замерами за 7/30/90 дней или всё время, график и историю. Изменение не рассчитывается при менее двух замерах за период. Анкетный вес не подменяет измерения. Форма замера открывается отдельно.

Поля даты ограничены шириной контейнера, числовые поля сохраняют размер текста 16 px. Safe area сохраняется. При существенном уменьшении visual viewport нижняя навигация скрывается, предотвращая перекрытие клавиатурой. Черновик подхода сохраняется при возврате из упражнения. Кнопка Telegram «Назад» работает на экранах упражнения, продукта и замера.

## Границы проверки

Playwright использует Chromium на ширинах 320, 375, 390 и 430 px. Во всех пяти вкладках и экране упражнения проверяется горизонтальное переполнение; создаются 24 скриншота. SDK проверяется через тестовый native bridge с платформой iOS. Это **не проверка реального iOS Telegram или Safari/WebKit**. В текущем пользовательском вложении есть только текст: исходные iPhone-скриншоты недоступны. Визуальный просмотр проводится по вновь созданным скриншотам Playwright.

Скриншоты доступны в артефакте `test-results` GitHub Actions, включая успешные запуски. В каталогах `ui-320`, `ui-375`, `ui-390`, `ui-430` файлы `tab-0`…`tab-4` соответствуют «Сегодня», «Тренировки», «Питание», «Прогресс», «Профиль»; `exercise.png` — отдельный экран упражнения.
